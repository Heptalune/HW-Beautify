# 动画效果 模组介绍

本组收录以「动态视觉过渡」为核心价值的模组：窗口、任务栏、菜单、图标的出现／消失／移动／变形动画，平滑滚动，光标放大，以及 3D 窗口切换动画。开启后界面会「动起来」，重点在动画过程与节奏，而非最终静态外观或新增操作能力。

## 模组详细介绍

### 1. Alt+Tab 翻转 3D（Vista 风格）

- **文件名**：`alt-tab-flip-3d-inproc.wh.cpp`
- **模组 ID**：`alt-tab-flip-3d`
- **版本**：1.7.3
- **原作者**：caliberda
- **注入进程**：windhawk.exe / explorer.exe
- **功能介绍**：将 Alt+Tab 替换为流畅的 Windows Vista 风格 Flip 3D 实时窗口堆栈

### 2. 桌面跑马灯淡出

- **文件名**：`desktop-marquee-fade.wh.cpp`
- **模组 ID**：`desktop-marquee-fade`
- **版本**：1.0.0
- **原作者**：angel_lov
- **注入进程**：explorer.exe
- **功能介绍**：松开鼠标按钮时，为桌面选择矩形添加平滑的淡出动画。

### 3. 文件资源管理器 WinUI 风格内容动画

- **文件名**：`file-explorer-content-animation.wh.cpp`

- **版本**：1.0.3
- **原作者**：crazyboyybs
- **注入进程**：explorer.exe
- **功能介绍**：为文件资源管理器内容区域提供流畅的 WinUI 风格页面过渡动画。

### 4. 晃动鼠标寻找光标

- **文件名**：`shake-find-cursor.wh.cpp`
- **模组 ID**：`shake-to-find-cursor`

- **功能介绍**：晃动鼠标时临时放大鼠标光标，类似 macOS 的"晃动以定位"功能

### 5. Win32 平滑滚动

- **文件名**：`smooth-scroll-win32.wh.cpp`

### 6. 任务栏自动隐藏秒显

- **文件名**：`taskbar-autohide-instant-show.wh.cpp`
