# 外观美化 模组介绍

本组收录以「改变界面静态或持续的视觉外观」为核心价值的模组：透明／模糊／亚克力背景、主题与样式器、窗口圆角与清晰度、图标与壁纸、Dock／灵动岛外观、对话框现代化等。重点在「看起来是什么样」，而非动画过程或新增功能。

## 模组详细介绍

### 1. 自定义窗口圆角半径

- **文件名**：`custom-corner-radius.wh.cpp`
- **模组 ID**：`custom-corner-radius`
- **版本**：1.4
- **原作者**：m417z
- **注入进程**：dwm.exe
- **功能介绍**：自定义 Windows 11 中的窗口圆角半径，使边角更加圆润或更加锐利

### 2. 动态任务栏透明度

- **文件名**：`dynamic-taskbar-transparency.wh.cpp`
- **模组 ID**：`dynamic-taskbar-transparency`
- **版本**：0.3.9
- **原作者**：11581
- **注入进程**：explorer.exe
- **功能介绍**：动态调整 Windows 11 任务栏 XAML 背景的透明度，适用于桌面、开始菜单、搜索、托盘弹出菜单、任务视图以及最大化窗口。

### 3. 文件操作样式器

- **文件名**：`file-operation-styler.wh.cpp`
- **模组 ID**：`file-operation-styler`
- **版本**：1.4.0
- **原作者**：digART
- **注入进程**：explorer.exe
- **功能介绍**：为原生资源管理器文件操作提供便携的自定义展示，采用皮肤安全的统一展示风格。

### 4. 手电筒桌面图标

- **文件名**：`flashlight-desktop-icons.wh.cpp`
- **模组 ID**：`flashlight-desktop-icons`
- **版本**：1.0.0
- **原作者**：dantepicachu
- **注入进程**：explorer.exe
- **功能介绍**：让桌面图标在闲置时半透明或不可见，并仅显示鼠标光标附近、位于可自定义半径范围内的图标。与 Wallpaper Engine 完美兼容。

### 5. 资源重定向

- **文件名**：`icon-resource-redirect.wh.cpp`
- **模组 ID**：`icon-resource-redirect`
- **版本**：1.3
- **原作者**：m417z
- **注入进程**：*
- **功能介绍**：定义各种资源（如 imageres.dll 中的图标）的替代加载文件，实现简单的主题化而无需修改系统文件

### 6. 动态视频壁纸

- **文件名**：`live-video-wallpaper.wh.cpp`
- **模组 ID**：`live-video-wallpaper`
- **版本**：1.1.1
- **原作者**：AKS HAY
- **注入进程**：explorer.exe
- **功能介绍**：使用硬件加速的 Media Foundation 渲染将 MP4 视频作为 Windows 桌面壁纸播放，并内置运行时性能分析器（按 `Ctrl+Alt+D` 切换 HUD）。

### 7. 锁屏动态壁纸

- **文件名**：`lock-screen-live-wallpaper.wh.cpp`
- **模组 ID**：`lock-screen-live-wallpaper`
- **版本**：1.1.0
- **原作者**：grn15RenS
- **注入进程**：LogonUI.exe / LockApp.exe
- **功能介绍**：将视频作为 Windows 11 锁屏和密码/登录界面的背景播放。1.1.0 起新增预览窗口（无需锁屏即可查看适配、颜色与速度效果，可选快捷键与托盘图标）、低电量省电模式（降帧率或降渲染宽度，或冻结为静止帧）、画面变暗、文件夹内视频的随机/顺序/固定播放顺序、动态 GIF 支持，以及音频淡入淡出。

### 8. Mac 灵动岛与程序坞

- **文件名**：`mac-island-dock.wh.cpp`
- **模组 ID**：`mac-island-dock`
- **版本**：3.2.0
- **原作者**：caliberda
- **注入进程**：windhawk.exe / explorer.exe
- **功能介绍**：屏幕顶部的灵动岛，类似 macOS 菜单栏和 iPhone 的灵动岛（时钟、控制中心、通知、媒体、托盘图标），并提供类 macOS 的程序坞来替代任务栏（或透明/原样的 Windows 任务栏）。3.2.0 起新增：命令的定时自动运行、显卡占用与温度显示、像 iPhone 灵动岛一样的实时活动、Faísca 小精灵（表情随电脑状态变化、五个小游戏、专属音效）、GlazeWM 工作区、Bar 隐藏成细线与贴边排布、翻译辅助导出、分享面板等大量功能。

### 9. 现代化运行对话框界面（适用于 Windows 10 和 11）

- **文件名**：`modern-run-dialog-ui.wh.cpp`
- **模组 ID**：`modern-run-dialog-ui`
- **版本**：5.0.104
- **原作者**：caotu2005
- **注入进程**：explorer.exe
- **功能介绍**：将经典的 Win + R 对话框替换为现代化的 液态玻璃（Liquid Glass） / Fluent UI。5.0 起整体改版为浮动胶囊式启动器：命令栏与历史记录、应用建议、计算结果、翻译分离为独立的圆角胶囊卡片，带平滑开合动画与智能居中，并新增默认 340px 的「迷你胶囊模式」、输入栏内的即时数学计算器（`1+1`、`sqrt(144)` 等）与内置多语言翻译模式（`文A`）。
